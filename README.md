# Microgrid RL 🔋

Reinforcement Learning agent for smart residential energy management.

## Project Structure
- `src/` — source code (environment, agents, training)
- `data/` — energy profiles and datasets
- `notebooks/` — experiments and visualizations
- `results/` — plots and evaluation outputs

## Algorithms
- Q-Learning (tabular baseline)
- Deep Q-Network (DQN)
